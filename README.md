# LLM Agent 个人知识库

一套长期维护的规则与技能库，用来约束 LLM Agent 的行为：规则分四层、技能按任务分类，两者都能被检索和调用。

- 规则：17 份，约 18 万字符（含技能），分四层
- 技能：45 个技能包，每个包含 `SKILL.md`、`_meta.json` 与运行登记
- 用途：给多个 Agent 共用同一套行为边界；换一个模型、换一个环境，规则仍然生效

## 结构

```
02_规则/            17 份规则文件
├─ 01_全局规则/     跨项目通用
├─ 02_项目规则/     按项目空间生效
├─ 03_测试专栏规则/  测试方向的补充条款
└─ 04_个人偏好/     个人协作偏好（模型切换、记忆写入、交付物组织等）

01_技能/            45 个技能包
├─ 01_测试/
└─ 90_共享配套/

03_技能目录与依赖/   技能之间的依赖与索引
```

## 四层规则怎么分工

| 层 | 管什么 | 典型内容 |
|---|---|---|
| 全局 | 跨项目、跨工具都成立 | 文件落点、冗余禁令、恢复点要求 |
| 项目 | 只在该项目空间生效 | 目录约定、交付物结构 |
| 专项 | 某个方向的方法 | 测试用例要素、缺陷报告格式 |
| 偏好 | 个人协作习惯 | 什么时候换模型、记忆怎么写、交付物怎么放 |

分层的意义：一份规则不该套所有任务。项目规则与全局规则冲突时以项目为准；偏好层只影响协作方式，不影响交付标准。

## 怎么用

1. 先读全局规则，建立边界；
2. 进入某个项目时叠加项目规则；
3. 遇到专项任务再加载对应技能包；
4. 偏好层按需加载。
